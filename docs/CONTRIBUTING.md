# Contributing to CyberSentinel AI

Thank you for your interest in contributing to CyberSentinel AI!

---

## 🛡️ Ethical Security Mandate

- **Strict Defensive Focus**: Contributions introducing active exploitation, credential theft, denial of service, or unauthorized scanning logic will be rejected immediately.
- **Scope Enforcement**: All scanning modules must strictly adhere to the abstract interface contract defined in `backend/app/scanner/interfaces/`.

---

## 📝 Pull Request Checklist

1. Fork the repository and create your feature branch.
2. Maintain strict TypeScript and Python typing standards.
3. Ensure all test suites pass (`pytest` and `npm run lint`).
4. Keep commit messages clear and structured (e.g. `feat(scanner): add abstract TLS analyzer interface`).
5. Open a Pull Request referencing the relevant issue.
