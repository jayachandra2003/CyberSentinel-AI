# CyberSentinel AI — Project Roadmap

## Overview
This document outlines the planned release milestones, upcoming scanner modules, and architectural roadmap for CyberSentinel AI following the **v1.6.0** stable release baseline.

---

## 🎯 Release Milestones & Priorities

### Current Baseline
- **`v1.6.0` (Completed & Released)**:
  - 5 Core Defensive Scanners (`DNS`, `WHOIS`, `SSL/TLS`, `HTTP Headers`, `Cookie Security`).
  - Dynamic 5/5 Module Execution Counter.
  - Weighted Risk Engine & Stable Finding IDs (`CK-001` - `CK-006`).
  - Full Dark Mode UI & JSON Export.

---

## 🔮 Future Release Roadmap

### `v1.7.0` (Planned — Technology Stack & Cookie Security Patch)
- Deferred UI/UX presentation refinements (badge styling, spacing adjustments).
- Technology Stack Detection Module (`TechScanner` — Web server, framework, CMS, analytics identification).
- Port & Service Footprinting Module (`PortScanner` — Top 20 common defensive ports).

### `v1.8.0` (Planned — Content & Crawler Reconnaissance)
- Sitemap & Robots.txt Auditor (`CrawlerScanner`).
- Broken Link & Redirect Chain Analyzer (`LinkScanner`).

### `v2.0.0` (Planned — Enterprise AI Remediation Suite)
- LLM-Powered Security Summary & Remediation Engine (`AISummarizer`).
- Scheduled Monitoring & Automated Email Alerts.
- Multi-User Organization Roles & API Token Management.
